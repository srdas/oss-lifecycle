# Description of notebooks in this folder for the paper's results

1. `model_forecasts.ipynb` : generates Tables I and III, Figures 4, 5, 6.
2. `developer_stats.ipynb` : generates Table II and Figures 5, 6, 7. 
3. `pypi_stats.ipynb` : generates Figure 8. 
4. `quadratic_fit.ipynb` : generates Figure 1. 

Other results:

- Figures 1, 2, 3 generated by `fit_bass.py` and `fit_innovation.py`.

To run the notebooks, place them in a separate folder. You can place the data files in a `data` folder and then make sure you point to them in the notebook.
